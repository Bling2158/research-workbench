# 科研工作台 | Research Workbench

一个面向研究生和科研人员的个人科研工作台，帮助你把 AI 对话、研究项目、文献与投稿进度整理在同一个地方。你可以先用虚构数据体验界面，再根据自己的研究领域和使用习惯进行配置。

这是一个自托管模板：本地使用时，数据保存在自己的电脑上；选择云端部署时，使用自己的 Supabase 数据库和服务账号。

## 功能

- **AI 对话**：配置模型密钥后使用对话助手，可选联网搜索与文献检索。
- **研究管理**：记录项目进展、研究决策、科研与生活记录，追踪论文投稿状态。
- **今日总览**：查看毕业进度、项目情况、截止提醒和周回顾。
- **AI 资讯**：在工作台中查看 AI 相关资讯。
- **MCP 接口**：让 Codex 或 Claude 等客户端读取和更新科研数据。生活记录和照片不进入科研 MCP 接口。

## 快速体验

需要 Node.js 22。下载或克隆仓库后，在项目目录运行：

```bash
npm ci --ignore-scripts
npm run demo
```

打开终端中显示的地址，即可使用虚构数据体验界面。AI 对话需要配置模型密钥；演示数据保存在 `.data-demo/`，删除该目录可重置。

## 用 AI 帮你搭建

在项目目录打开 Codex 或 Claude Code，输入：

> 请按照 SETUP_WITH_AI.md 帮我搭建这个工作台。

也可以直接阅读 [SETUP_WITH_AI.md](SETUP_WITH_AI.md)，按步骤完成个性化、本地使用或云端部署。需要登录账号和填写密钥时，请自行在对应服务页面或本地 `.env` 文件中操作。

## 本地使用

复制 `env.example` 为 `.env`，按需填写配置。使用 AI 对话时，至少配置一个模型密钥；不配置云数据库时，数据保存在本机 `.data/`。

```bash
npm ci --ignore-scripts
npm start
```

按照终端提示打开工作台。本地访问密钥保存在 `.data/access-token`；Windows 用户也可以双击 `启动工作台.cmd`。请妥善保管访问密钥，不要将 `.env` 或个人数据提交到公开仓库。

## 个性化与部署

- `public/config.js`：设置工作台名称、助手名称、时区、毕业日期和论文目标。不填写日期时，毕业进度卡片会隐藏。
- `agent/instructions.txt` 和 `agent/skills.json`：调整助手行为和科研、写作方法。
- `env.example`：查看模型、搜索、数据库和 MCP 等环境变量的说明。
- **可选云端部署**：使用 Vercel 和自己的 Supabase 项目。具体步骤见 [搭建指南](SETUP_WITH_AI.md)。连接 Vercel 后，推送到 `main` 可触发部署；构建时运行测试。

## MCP 接口

MCP 支持分层读取科研信息：`get_overview` → `get_project` → `search_records` / `get_record`，也可以用 `get_changes` 接续工作。配置方法见[搭建指南](SETUP_WITH_AI.md)。建议在客户端将写入工具设置为每次确认，并妥善保管 MCP 访问令牌。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `public/` | 页面、交互、样式及个人配置 |
| `api/`、`lib/` | 后端、模型、MCP 和数据管理 |
| `agent/` | 助手说明与技能 |
| `test/` | 使用虚构数据的测试 |
| `schema.sql` | 新 Supabase 数据库的初始化脚本；不要对已有数据的数据库重复执行 |

运行 `npm test` 可执行项目测试。

## 服务与费用

模型调用和 Tavily 联网搜索的费用取决于各服务商的规则和用量；文献搜索使用 OpenAlex。AI 资讯来自 AIHOT，使用时请查看其当前服务条款和费用。
